# Level 1: Beginner Level:

Welcome to the Beginner JavaScript Developer Documentation! 🚀
If you're just starting your journey in JavaScript, you're in the right place. Let's get started!

## Milestone 1

### Basic and Control Flow. (5Days) 25Hrs

## Topic

#### 1. Basic Syntax: ( 3 Days ) 15Hrs

- Declaring and assigning variables.
- Data types in js.
- Operators and Operator precedence (e.g., +, -, \*, /, ===, !=, &&, ||).
- Basic Input/Output: console.log() and prompt().
- Code comments (Single line and Multiline).

#### 2. Control Flow:(2 Days ) 10hrs

- Conditional statements (if, else if, else, Ternary Operator).
- Basic comprehension of loops, including for and while, for repetitive tasks.
- Understanding the role of boolean expressions in conditionals.
- Switch Statements: Basic understanding.

## Milestone 2

### Scope & Functions (5Days) 30Hrs

## Topic

#### 1. scope: ( 3 Days ) 15Hrs

- Closure.
- Hoisting.
- var, let and const scope.
- Prototypes basics.

#### 2. functions:(3 Days ) 15hrs

- Ability to define and call functions.
- Using parameters and returning values.
- Higher order functions.
- Pure functions.
- call apply and bind.

## Milestone 3

### Objects & Arrays (5Days) 25Hrs

## Topic

#### 1. Objects (2Days) 10Hrs

- Understanding of what objects are and how to create them with key-value pairs.
- Basic comprehension of object properties and how to access them using dot notation (e.g., object.property) and bracket notation (e.g., object['property']).
- Awareness of object literals and basic object manipulation.
- Ability to store and retrieve data in arrays and objects.

#### 2. Arrays (3Days) 15Hrs

- Creating and manipulating arrays.
- Ability to access array elements by index (e.g., array[0]) and iterate through arrays using loops.
- Understanding of basic array methods like push(), pop(), maps, filter , reduce , shift(), and unshift().

## Milestone 4

### String Manipulations & Promises , Async (5Days) 25Hrs

## Topic

#### 1. String Manipulations (2Days) 10Hrs

- Basic understanding of working with strings.
- String concatenation and interpolation.
- Common string methods like substring(), indexOf(), split(), join() and toUpperCase().

#### 2.Promises and async (3Days) 15Hrs

- Promise basics.
- Promise states (Pending|Fulfilled|Rejected).
- Creating a promise.
- Promise chaining.
- Handling Promises Result
- Async/Await.
- Error handling in promises

## Milestone 5

### Dom manipulations & Synthetic Events (5Days) 25Hrs

## Topic

#### 1. Dom manipulations (4Days) 20Hrs

- What is DOM?
- How it works.
- DOM selectors.
- Event handler.
- Creating dom element.
- Traversing dom.

#### 2. Synthetic event (1Days) 55Hrs

- Basic knowledge of handling events and attaching event listeners.
- Adding event listeners to respond to user actions.
- Handling common events like clicks and inputs.
- Handling form.
- Event Propagation.

## Milestone 6

### Error Handling and ES6 Concepts. (5Days) 25Hrs

## Topic

#### 1. Error Handling: ( 3 Days ) 15Hrs

- try, catch and finally.
- understand how errors affect program flow.
- Handle simple exceptions.

#### 2. ES6 Concepts:(2 Days ) 10hrs

- Arrow functions.
- let and const.
- Template literals.
- Spread and Rest Operators.
- Promises.
- Destructuring assignment.
- Array methods like map, filter, reduce, forEach and so on.
- Modules (import and export)
